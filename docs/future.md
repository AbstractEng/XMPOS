# Community contribution ideas

Start with reproducible bugs and small changes covered by shared native/browser
fixtures. Public proposals should describe the musical workflow, behavior and
verification, without private conversation or personal context.

- Improve sampler review, slices, loop/level behavior and original sound examples.
- Add bounded declarative instruments/effects and public SDK examples.
- Improve clip, scene and song editing while preserving undo and project compatibility.
- Extend keyboard/touch accessibility and screen layout across shared C++ adapters.
- Improve project transfer, portable assets and documentation of schema/migrations.
- Measure timing, persistence and recovery limits on separately authorized profiles.
- Help qualify One/One+ through a separate model profile and safe recovery route.

Ideas are not shipped features or hardware permissions. Discuss scope in an
issue and follow [contribution guidance](../CONTRIBUTING.md), [device boundaries](../AGENTS.md)
and [release status](../RELEASE.md).
