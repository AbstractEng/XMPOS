# Hardware and platform scope

XMP is a community workstation framework with host, browser and emulator
adapters. The initial physical profile is Live Mk1 / ACV8, exactly MPC OS 3.10.1,
tested on one unit. Other models require their own qualification. MPC One/One+
are planned ports; One G2 is a separate firmware family. Force is excluded.

Use the [compatibility matrix](compatibility.md), [Live integration profile](live-mk1-device-plan.md),
[developer setup](developer-guide.md), [installation](install-live-mk1.md) and
[stock recovery](recover-live-mk1.md). A cable connection does not authorize
active device access. Keep personal device identifiers and observations private.

Public source and tests use generic profiles and synthetic identities. No
individual purchase, service history, device inventory or credentials belong
in the community repository. Read AGENTS.md before proposing hardware work.
