# Community baseline: verified scope and known issues

This is an experimental developer baseline. [Current release status](../RELEASE.md) identifies candidate 0.1.0-dev.20261121, staged private downloads, evidence and remaining work. [The baseline checklist](launch/baseline-release.md) defines the minimum scope. Historical receipts do not qualify later binaries.

| Area               | Current limit and practical action                                                                                                                                                                                                                                                                               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Installation       | Complete Intel Mac and Windows preview kits are staged privately. Current exact-file clearance and physical installation/handover/restoration checks remain pending. Earlier clearance applies only to the older candidate; see [release status](../RELEASE.md).                                                 |
| Compatibility      | One physical Live Mk1 / ACV8, exactly MPC OS 3.10.1. One/One+ are planned ports; One G2 is separate. Installation on those models is disabled. Force is excluded.                                                                                                                                                |
| Saving             | Native autosave waits for Stop. Wait for **Saved on stick** before restart/power-off. **Unsaved changes**, **Saving to stick** and **Save failed** are not permission to power off. Preserve an independent backup of personal work.                                                                             |
| Music evidence     | Older owner play/control/save checks are historical. The current candidate has shared Device and ARM one-track save/cold-reopen evidence, but no new physical play/save/control observations.                                                                                                                    |
| Timing/reliability | The [diagnostic soak](live-mk1-soak.md) recorded late-note events. It is not a clean eight-hour stress pass. Worst-case workload, physical input-to-output latency, headroom, temperature and memory stability remain unqualified.                                                                               |
| Sampling           | Physical input sampling is experimental and unverified. Browser demonstrations and bridge output taps do not qualify the inputs. It is excluded from the verified baseline workflow.                                                                                                                             |
| Updates            | The old bridge cannot safely update itself. Use the owner USB-copy bootstrap, then the corrected checked promotion/fallback path. Host/ARM fault tests do not simulate a physical FAT power cut. See [updates/recovery](live-mk1-updates.md).                                                                    |
| Sound/FX edits     | Some native graph changes apply on Stop; follow the displayed pending state. Loading latency is not qualified.                                                                                                                                                                                                   |
| SDK                | Offline declarative instrument/effect processing and source-built examples are supported on the declared Mac host. Arbitrary executable packages, native Live UI/module loading, VST/device adapters and real-time/physical parity are not supplied by this SDK profile.                                         |
| Browser/VM         | The shared Device workflow passed 86 common steps and 17 screenshot comparisons. ARM boot/views/play/Stop/save/cold-reopen passed for a one-track fixture, but bridge audio capture and a cold-boot screenshot timed out under emulation. Complete ARM bridge/audio and physical reliability remain unqualified. |

Original XMP code is open for contributions. [Report a reproducible issue](https://github.com/AbstractEng/XMPOS/issues) with the candidate/SDK version, host and small original fixture; see [contribution guidance](../CONTRIBUTING.md). Do not attach firmware, bridge credentials, device identifiers or personal recordings/projects.
