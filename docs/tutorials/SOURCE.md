# Written tutorials and practice assets

Use the [published manual](https://abstracteng.com/xmpos/manual/) for the narrated
course. Video files, private narration tooling and voice-service configuration
are excluded from this source snapshot. The included original practice audio,
projects, captions and diagrams support local software testing.

Optional capture helpers can generate local media in ignored build/artifact
folders. Do not add narrated or personal recordings to the public source export.
