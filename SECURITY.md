# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/AbstractEng/XMPOS/security/advisories/new).
Do not disclose exploits or credentials in a public issue. Include the affected
revision, environment and a small original reproduction with redacted results.
Never attach firmware, device identities, tokens, private projects or recordings.
If private reporting is unavailable, open an issue requesting a private contact
without including the sensitive material. This community baseline has no response-time SLA.
