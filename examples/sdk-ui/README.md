# Custom SDK sound card

Installed example: run `node node_modules/@xmp/sdk/examples/sdk-ui/render.mjs sound-card.html` from your contributor project. The output is a self-contained interface over an original offline-rendered tone. Read the [example walkthrough](../../docs/sdk/examples.md) before modifying it. This is trusted source, not executable content imported from a package. It starts no server and accesses no physical device.
