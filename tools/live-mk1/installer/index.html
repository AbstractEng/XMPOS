Verify your Live in stock MPC OS

Complete this check before preparing the USB key on a first installation if update mode cannot report the model or rootfs size. Start the Live Mk1 in official MPC OS 3.10.1 and enable Developer Mode using Akai’s documented procedure. Connect this computer and the Live to the same local network. Enter the IPv4 address shown on the Live; the installer does not scan for devices.

Enter the Live’s SSH password only in the native password prompt. It goes directly to SSH and is not saved. This check does not change device storage or settings. It creates a private unit verification profile on this computer; the USB preparation step also saves it on your key. During the later fastboot check, the serial must match this same unit.

2Prepare your XMP USB key

Connect a removable FAT32 USB key to this computer. This copies the XMP system to the key, verifies it and preserves existing projects, samples, token and prior images. It does not format the key. A private verification profile for this MPC is kept on the key when available.

3Set up the MPC connection

One-time setup downloads verified Android Platform-Tools directly from Google. This sets up communication with the MPC; it does not write the USB key or the MPC.

Destination: MPC internal rootfs

4Install the MPC loader

With the XMP key out of the MPC, power the Live off. Hold FULL LEVEL + ERASE + PAD BANK C/G while powering it on. Connect its USB-B computer port to this computer.

This preview reads device information and verifies the image. It writes nothing to the MPC.

Destination: MPC internal rootfs · USB key unchanged

Confirm installation

Only the MPC root filesystem will be rewritten. The bootloader and partition table are untouched. Keep power and USB connected until completion.

After the loader finishes

Safely eject the prepared USB key from this computer. Power the Live off, insert the key into its USB-A port, and power it on to boot XMP. The installer’s MPC flash step does not copy anything to the key.

Removing the key boots stock through the loader. Choose Restore stock 3.10.1 for a full return to the official root filesystem.
