QUICK START / YOUR FIRST LOOP

Make your first loop

Open XMP & make a beat ↗Have music open? Save it before starting a new project.

  1. Start fresh

    Hold MENU + PAD 5 for Project. PAD 13 opens New; follow the confirmation. Your original drum kit is ready.

  2. Make a clip

    Press A → 16 LEVEL → DATA DIAL. You now have a 16-step clip on track 1.

  3. Put down the kick

    Hold SHIFT + PAD 1 to select Kick, then release SHIFT. Press PAD 13, 9, 5, 1: those are steps 1, 5, 9, 13.

  4. Add the backbeat

    Hold SHIFT + PAD 2 to select Snare. Release SHIFT, then press PAD 9 and 1 for steps 5 and 13.

  5. Hear it

    Press PLAY START. There’s your loop. STOP ends playback. Watch the exact pad presses.

  6. Keep it

    Press STOP and wait for Saved; on hardware, Saved on stick. To name a copy, hold MENU + PAD 5, then PAD 16 for Save as. In the browser, Download saved project keeps a portable file backup.

Add a bass: B → MENU + PAD 16 → PAD 15 chooses Synth on a new track. Try the bass lesson, or launch your clips from the pads.

On the Live, hold MENU or SHIFT with the next control. In the browser, click MENU or SHIFT, then the control. Pad 1 is bottom left; pad 13 is top left.

THE INSTALLER DOES THE FILE WORK

No terminal commands to copy.

It checks the official updater, prepares recovery files on your computer, builds the USB system locally, and verifies the copy. The USB step preserves projects and samples; it does not format the key.

The final, owner-confirmed step replaces the MPC’s internal root filesystem. It leaves the bootloader and partition table unchanged. Keep the power adapter and USB cable connected until that step finishes.

Written steps: prepare the files and USB key

1 / ON YOUR COMPUTER

Prepare the files and verify your Live

  1. Check the starting version. On the MPC, open Preferences → Info and confirm 3.10.1. If the model or version differs, stop here and use the compatibility guidance for that build. Picking a nearby updater version will not make it compatible.
  2. Open XMP OS Installer. On a Mac, open XMP OS Installer.app. On Windows, keep XMP OS Installer.exe beside its supplied resources folder. The owner installer includes its runtime; you do not need to install Node, Python or Docker.
  3. Select the official updater. Click Choose updater… and choose the official Gen 1 3.10.1 updater for your computer. It is obtained separately from Akai, rather than bundled as firmware in XMP.
  4. Click Prepare installation files. Let the activity indicator finish. The installer checks the signature and exact payload, prepares the loader and stock recovery locally, and assembles the system that will go on your key. It reuses verified files on later runs.
  5. Verify the stock Live before its first installation. Leave the MPC running stock 3.10.1. Put it and the computer on the same local network. Enable Developer Mode using the steps below, then enter the MPC’s own local IPv4 address in Live’s local IPv4 address. Tick the read-only verification acknowledgement and click Verify stock Live.
  6. Use only the native password prompt. If prompted, type the Live’s SSH password into the installer’s native secure prompt. Do not send it in a chat, type it into the address box or put it in a script. The verifier reads identity and rootfs metadata; it does not change storage or settings.
Where do I enable Developer Mode and find the address?

In stock MPC OS, open Preferences → Info. Following Akai’s SDK procedure, tap the version value three times, the serial-number value twice, then the firmware-version value once. Developer Mode starts the SSH service used for this read-only check.

Find the MPC’s local IP in the Preferences Wi-Fi tab (hold SHIFT to reach it) or the Ethernet tab. Use the address shown on your own unit; 192.168.1.50 in the video is only an example. The installer does not scan your network.

This procedure follows Akai’s official SDK installation notes. You control the device’s network and Developer Mode settings.

You are ready when: the installer reports that loader and stock recovery are verified, and the stock verification reports your Live Mk1 on 3.10.1. The private verification profile is kept on the computer and copied to the prepared key. It must match the same Live during installation.

2 / ON YOUR USB KEY

Let the installer create the XMP key

  1. Connect the key to your computer. Click Refresh USB keys. Choose your removable FAT32 key from Choose your USB key; check its label, model and capacity.
  2. Confirm the destination. Tick I selected the correct USB key and backed up my work. This confirmation is for the key, not the MPC.
  3. Click Prepare USB key. Wait while it copies the XMP system and verifies it. The installer preserves existing projects, samples, the per-key token and prior images. It checks free space, so there is no need to guess whether the copy fits.
  4. Wait for the verified result. Look for Copied and SHA-256 verified. An activity indicator or a partial progress bar means work is still in progress.
  5. Click Safely eject USB key. If the platform asks you to eject in its file manager, follow that instruction. Keep the prepared key ready, but leave it out of the MPC during loader installation.

You are ready when: the key has been copied, verified and ejected. You do not need to copy a system image, recovery image or token by hand.

My USB key is not listed

Check that it is an external removable FAT32 key, reconnect it to the computer and choose Refresh USB keys. The installer does not convert exFAT/NTFS or format drives. Use an already prepared FAT32 key; do not select MPC storage or an internal computer drive. If it reports insufficient space, choose another suitable key or free space after backing up its files, then refresh and select it again.

Written steps: install the loader and start XMP

3 / ONE-TIME MPC LOADER INSTALL

Check first. Confirm once.

  1. Set up the computer connection. In the installer, review Google’s linked Platform-Tools terms, tick the acceptance box and click Install connection tools. This one-time download sets up the computer; it does not write the key or the MPC.
  2. Save, power off and remove the XMP key. Keep the Live on its power adapter. Hold FULL LEVEL + ERASE + PAD BANK C/G while powering on with the rear power button to enter update mode.
  3. Connect the data cable. Connect the Live’s USB-B computer port to the computer running the installer. Leave the prepared USB key out of the MPC.
  4. Keep Install XMP USB loader selected. Click Check Live and image. This is a read-only preview: it checks the connected Live and verified image before any MPC write. On units whose fastboot cannot report all metadata, the earlier stock verification supplies that same unit’s measured identity/capacity evidence.
  5. Read Confirm installation. Check the operation, acknowledge saved work/power and the stock 3.10.1 starting point, then type XMPOS exactly. Click Install loader yourself. This is the step that writes the MPC’s rootfs, not the USB key.
  6. Let the installer finish. Keep power and the data cable connected until it reports Finished and the Live reboots. A changed unit/image, missing measurement or failed check stops the process; recheck the stated issue instead of bypassing it.

You are ready when: installation has completed and the Live has rebooted. The prepared key is still separate and ready for the next stage.

The confirmation expired or Install loader is disabled

Run Check Live and image again, review the fresh operation, tick both acknowledgements and type XMPOS exactly. The preview expires after five minutes or a changed selection. Installation also requires a key prepared by the installer. A refusal is a useful checkpoint: keep its message and use the installer’s operation log rather than trying raw flash commands.

4 / YOUR FIRST XMP BOOT

Insert the key and make a small loop

  1. Power the Live off. Insert the prepared key into a USB-A host port, then power on. The loader starts XMP from the key.
  2. Check that XMP opens. Look for the expected build and bridge indicator. Use the Quick start with a disposable practice song; make one small edit and note its tempo or a mixer setting.
  3. Stop and let it save. Press STOP and wait for Saved on stick. Native autosave waits for playback to stop. Saving to stick, Unsaved changes and Save failed are not completed saves.
  4. Check the saved copy. Shut down normally, boot the same key again and reopen the song. Confirm the edit, tempo/mixer setting and playback. Now continue with the music lessons.

Everyday routine: key in to start XMP; STOP and wait for Saved on stick before shutdown or removing the key. Your XMP projects and samples live on the key.

RETURN TO MPC OS / TWO CHOICES

Switch for today, or restore fully

Use MPC OS for a session

In XMP, press STOP, wait for Saved on stick and shut down normally. Remove the XMP key and power on. The installed loader hands over to Akai’s MPC OS.

The loader stays installed. To use XMP again, power off, reconnect your prepared key and power on.

Remove the loader completely

Keep the official 3.10.1 updater and local recovery files. With the key out, enter update mode and connect USB-B to the computer. In the installer, select Restore stock 3.10.1 → Check Live and image.

Review the stock operation, tick the acknowledgements and type XMPOS. Click Restore stock yourself and keep power/USB connected until completion. Cold-boot without the key and confirm official 3.10.1 and your usual projects/storage.

If a step does not finish
  • Wrong updater/version: use the exact official Gen 1 3.10.1 updater for this build and your computer. Do not edit a checksum or reuse files from another release.
  • Stock verification will not connect: check Developer Mode, the MPC’s own local IPv4 address and the shared network. Keep credentials in the native prompt. The installer does not discover an address for you.
  • Live not found in update mode: check the three-button power-on combination, the USB-B data cable and the connection-tools stage. Disconnect other update-mode instruments; the installer requires exactly one supported Live.
  • Copy still running: leave the key connected and wait for the verified result. After a reported copy error, resolve the message and prepare the key again; do not treat a partial copy as ready.
  • Connection ends during an MPC write: keep power connected and reopen the installer to inspect its log. Do not power-cycle or retry blindly. Use the reviewed stock recovery route if recovery is required.
  • XMP does not start after a completed install: power down normally before moving the key. Check that the key was verified and is in USB-A. You can use a no-key stock boot or the full stock restoration route above.

Keep the official updater, recovery files, generated images and private verification profile local. Hardware input sampling remains experimental and is not part of this first-boot lesson.

Song chain: Intro → Verse → Intro. Returning to Intro reuses the same clips. A scene references a clip; it does not make a copy. Editing a reused clip changes it in every scene that selects it.

Samples are sound; clips are performances. A recorded or imported sample goes into the project's sample pool. Kit pads assign those sounds or slices. Clips hold the notes, rhythm and automation that play the track's instrument.

Program the MIDI source clip and press PLAY START; the destination needs no clip. Both tracks’ levels and mutes apply, and audio uses the destination mixer strip. Routing is undoable and saved in portable projects and autosave. Missing or cyclic destinations stay silent with their saved state retained. No physical MIDI port is opened.

Import, trim and slice

  1. Select a pad and use Pattern → Import WAV, or choose an existing Project sound in Sounds.
  2. Set Start frame and End frame in the waveform editor. Use Crop to selected frames, Reverse or Normalize to shape playback. These edits preserve the original sample data and support Undo.
  3. For multiple slices, enter increasing frame boundaries such as 0, 1200, 2400, 3600 and click Assign slices to successive pads. Each range uses the same original asset.

RIFF WAV import accepts PCM16/24/32 and float32. Stereo input is downmixed to mono. A sample must fit the 4 MiB file, ten-second and 480,000-frame limits; unsupported encodings are rejected.

Build a synth part

Choose the subtractive synth machine, a preset and sine, saw or square waveform. The 32 presets cover Classic, Pop & rock, Electronic & dance, and House & acid; on the Device Sound page, − and + turn the preset bank and the pads choose. Adjust the tone, ADSR envelope, resonance, filter envelope, detune and glide controls, then play the pads as notes. Save patch and Open patch exchange patch JSON. Add pitched notes in Pattern, or set Selected step note and Length in Sounds and click Apply note & length for the selected step.

Use Panic · release notes if you need to release held voices immediately.

05 / NOTES & PATTERNS

Patterns & note recording

Device: Press 16 LEVEL. Hold SHIFT + a pad to select a sound or note, then release SHIFT and use the grid to toggle steps. Time starts on top-left PAD 13. Read the Q-Link labels to edit the selected hit. Try the velocity lesson.

Detailed editor instructions: Advanced Studio. For the default hardware-style flow, use Start a track and the Live Mk1 button map.

Step entry

Select a track, scene and pad. Choose 16, 32 or 64 Steps. Select inspects an existing hit without removing it; Draw toggles hits. Set velocity and probability directly, or use Delete hit. Clear pad pattern removes that pad’s legacy hits and detailed notes from the current clip. Undo restores the edit.

Polyphonic note entry

  1. In Pattern → Notes, groove & automation, choose a Pattern.
  2. Enter a zero-based Position, comma-separated MIDI notes and a Note length measured in sixteenth steps. For example, position 0, notes 48, 55, 60, length 4.
  3. Click Add chord on selected pad. Select rows in the note list to delete, quantize, restore played timing, or apply length and expression.

Duplicate pattern copies the pattern and selects the new clip in the current scene. A track can hold up to sixteen clips. Shortening a clip removes notes starting outside its new loop and truncates crossing durations.

Record a note pass

  1. Choose the destination track and Pattern, then click Record note pass. This starts transport if stopped; during playback it overdubs the remaining current clip cycle.
  2. Play pads or mapped computer keys. Optional Clocked note repeat uses the selected division and Repeat velocity.
  3. Click Finish note pass or Stop. The pass becomes one undoable edit.
  4. Select recorded note rows, choose a Quantize grid and use Quantize selected. Restore played timing returns to the captured timing rather than compounding previous corrections.

Changing the project during a pass can invalidate its destination. Download captured pass preserves the latest draft as JSON when available. Draft re-import is not implemented.

06 / FEEL & MOVEMENT

Groove & automation

Detailed editor instructions: Advanced Studio. For the default hardware-style flow, use Start a track and the Live Mk1 button map.

Swing ranges from 50% straight to 75%. Triplet displays 66.7% and uses an exact 2:1 ratio. Note Microtiming shifts an onset by up to ±0.49 sixteenth steps while keeping it inside its clip. Note probability uses 0–1; legacy step probability displays 0–100%.

Select note rows and use Apply length & expression to selected for microtiming, probability and conditions: always, first, not-first, fill, not-fill, every-2 or every-4. Fill held is a manual toggle. Probability is repeatable for the saved seed and musical cycle; this is not a fresh random roll on every export.

Parameter locks

Choose a Parameter and normalized value in Notes & automation, enter a step position, then click Lock at entered step. A lock lasts that sixteenth step. Remove it with Remove lock at entered step. Installed-machine and enabled-mixer parameters appear when available.

Modulation and recorded gestures

Use Set modulation source for a macro offset or a sine LFO with a chosen amount and cycles per clip. To record a parameter gesture, select its Parameter, choose an Automation mode and click Record automation pass. Move the normalized value control, then Finish or Stop.

Touch
Records touched intervals and returns to the underlying lane on release.
Latch
Starts at the first touch and holds its final value until the pass ends.
Write
Writes the recorded interval from its start.

Locks override the base automation value; macro/LFO offsets are then added and clamped. Smooth control changes avoid abrupt jumps. Unavailable or replaced machine targets stay saved and inactive instead of attaching to another control.

07 / ARRANGEMENT

Scenes & song chains

Device: MAIN opens Clips. Pads launch the visible slots; press a playing clip again to stop its track. Turn and press the dial to launch a whole scene. MENU + PAD 10 opens Song, where pads add scenes to the chain. Try pad launching.

Detailed editor instructions: Advanced Studio. For the default hardware-style flow, use Start a track and the Live Mk1 button map.

During playback, scene buttons queue a launch at the next bar. All selected clips restart from their beginning; an empty slot stops its track. While stopped, choosing a scene prepares it for Play.

Launch clips independently

  1. Stop and open Perform. Opening it turns on the performance preview.
  2. Choose Track and Clip, then Queue clip. Other tracks keep their position. Stop track at next bar stops only that owner.
  3. Cancel queued launch removes an uncommitted intent. The preview schedules ahead by about 100 ms, so a boundary already sent to the engine cannot be canceled retroactively.

A manual launch leaves song mode. An independently launched clip can differ from the editor’s scene selection; choose the track and pattern explicitly before editing it. The expandable Track and scene clip grid provides another launch surface.

Build a finite song

  1. Choose a Scene and click Add scene to chain for each song part.
  2. Set each occurrence’s Repeats; use Move up or Remove to edit the order.
  3. Set Song end → Stop for finite export, or Loop for continued performance.
  4. Play song starts at the beginning. Resume saved position uses the saved occurrence and offset.

A scene cycle follows its longest clip, with at least sixteen steps. Shorter clips repeat inside it. Live chain edits apply when the currently playing occurrence completes.

Mute, solo and macros

Performance mute/solo releases the affected source notes while shared effect tails can continue. Add a macro for a selected target and Assignment amount, then move its slider; 0.5 is its neutral midpoint. Record performance controls captures mute, solo and macro movements while playing. Finish or Stop commits one undoable pass. Download performance draft preserves a recoverable draft; draft re-import is pending.

08 / BALANCE & SPACE

Mixing & effects

Device: MENU + PAD 11 opens Mix. Top pad rows select tracks, bottom rows mute, and SHIFT + a bottom pad solos. Q1 adjusts the selected track’s level. Read the four knob labels before turning. Try the mix lesson.

Detailed editor instructions: Advanced Studio. For the default hardware-style flow, use Start a track and the Live Mk1 button map.

  1. Stop playback and open Mix. Opening it turns on stereo mixing as one undoable change, so older projects keep their sound until you open Mix.
  2. Select a track. Set Track gain, the existing Gain effect, pan and sends A/B. Both shared returns feed master.
  3. Choose Effect location, Slot and Effect, then Set effect. Fill Insert 1 before Insert 2. Graph changes require Stop.
  4. Adjust effect controls, bypass, or use Save preset/Open preset. Rhythmic filter / delay preset supplies an original clocked starting point for those effects.

09 / CAPTURE AUDIO

Recording & resampling

Device: MENU → Sample edits the selected pad or imports a WAV take in the browser. Trim, fade, tune, reverse or slice, audition the draft, then Keep edit or Discard. Watch sample editing. Native Live input takes are owner-operated, with stopped transport and a ten-second limit; the browser tutorial does not record hardware input.

Detailed editor instructions: Advanced Studio. For the default hardware-style flow, use Start a track and the Live Mk1 button map.

In Sounds → Record a two-bar take, choose WAV test input or Built-in MacBook microphone. The microphone option needs the local Mac development server and compiled native helper; a static build or non-Mac host does not provide that service.

  1. Select the destination pad. For WAV input, click Choose WAV input and select a supported file.
  2. Enable Monitor input levels and click Arm. Arming validates the take; it does not start a microphone stream.
  3. Click Start recording. Allow macOS microphone access if requested. The microphone path uses the built-in input only; its meter is visual monitoring, without a speaker return.
  4. Review the result and choose Keep take on selected pad. Capturing alone does not replace the project sound. Keeping a take is undoable.

Two bars are eight beats at the armed tempo. A take must fit ten seconds, 480,000 frames and the remaining project sample budget. Very slow tempos or insufficient space can prevent arming. Short input can produce an interrupted but recoverable take; follow the status message and download option when offered.

Resample two bars of master renders the current scene’s master output into a new mono asset on the selected pad without opening a microphone. Stereo is folded to mono. Note passes and automation passes are separate from audio recording.

10 / KEEP YOUR WORK

Saving & recovery

Detailed editor instructions: Advanced Studio. For the default hardware-style flow, use Start a track and the Live Mk1 button map.

Device: save, name and reopen

STOP and wait for Saved, or Saved on stick on the Live. Hold MENU + PAD 5 for Project. PAD 15 saves the current project; PAD 16 opens Save as. Enter a name on the screen and PAD 14 confirms it. PAD 14 on Project opens the saved-project browser. Select your entry and press the dial to reopen it.

In the browser, use Download saved project in the host bar after saving. Keep that .xmpsong outside the browser as a backup. To import a file, Add library files puts it in Browse; open Projects and load it there. On hardware, saved files are on your XMP USB stick. Watch Save and Reopen.

Advanced Studio: autosave and portable copies

Edits autosave to IndexedDB on this browser and origin. Check the footer for Saved on this computer or an error. Opening another browser, changing the address/port, private browsing or clearing site data can change or remove that local store.

Save project in Advanced Studio downloads a .xmpsong file. Keep Package samples with song checked to include the project's sounds once each. The file carries clips, scenes, song order, slices, MIDI routing and machine state; open it in another XMP browser or Device build and continue editing. It does not copy your full sample library.

Uncheck Package samples with song for a smaller file that needs matching sounds in the destination's local library. Missing sounds are listed and your current song stays open. Choose Locate missing samples (WAV) to find the original audio; moved and renamed files work when their contents match. A different sound with the same name is rejected. For generated sounds, use a packaged copy instead. Clearing browser data can remove cached samples, so keep a packaged backup.

Open project reads current .xmpsong files and supported older .xmp.json files. Save legacy copy includes samples in the older format for XMP previews that cannot read the new format. Download a copy before opening another project or clearing browser storage. A download request is not proof the file was saved successfully.

Undo and Redo cover project edits in the current session. Saved projects use schema version 8; supported versions 1–7 migrate without intentionally changing their musical data. History is a session editing tool, not a substitute for portable backups.

Recovery differs by environment

Studio can restore a previous valid autosave while retaining a damaged snapshot. Invalid imports preserve the project you were editing. If local storage is unavailable, use portable downloads.

The VM has its own file-backed data disk and committed/previous project generations. It validates project and asset hashes after reboot. A valid previous generation opens read-only when the primary is corrupt. If none is valid, it preserves the files instead of replacing them with an empty song. An explicit recovery-export command writes a recovery archive inside the VM disk; it is not a browser download.

13 / BOOTABLE DEVELOPMENT IMAGE

Standalone OS console

The independently booted Linux guest runs in QEMU on the Mac. It has a text music console, its own storage and original sounds. It has no network interface, host shares or USB passthrough. The graphical Studio interface and full continuous native music engine are still pending in this environment.

From the project’s terminal, with the existing toolchain and image:

npm run os:console

If the image is missing or you need to incorporate changed source, first run npm run os:build. The console prints its boot identity and stores its own virtual disk per image build.

Missing types retain saved state. This foundation does not itself provide a VST host, Eurorack/CV adapter or ported vendor machines.

The command-line workbench scaffolds original instruments/effects, builds bounded declarative packages, tests them and renders a short offline WAV. Run these from the repository root after dependencies are installed. Use fresh output paths; creation preserves existing files.

16 / GET UNSTUCK

Troubleshooting

I cannot hear anything

In Device view, select a Kit or Synth track, press SHIFT + MAIN for Play and try a pad. A click or pad press starts browser audio. In Advanced Studio, choose Enable audio first. Check system output, master/track levels, mute/solo and project samples. An unrouted MIDI machine is event-only; select a valid internal MIDI destination to hear it. Check the source and destination levels and mutes. The VM console captures to a file. Press Play again after returning from a hidden tab.

The keyboard pads do not respond

Finish any value or name entry first. The Device keyboard pads follow 1234, QWER, ASDF, ZXCV from top to bottom; physical pad 1 is Z. In Advanced Studio, click a non-control area before playing with keys. Use the on-screen pad labels to match the four keyboard rows.

I am editing a different pattern from the one playing

Independent launches can override the sounding clip without changing the scene’s edit map. Select the correct Track and Pattern explicitly, or launch a scene to return to a scene-based selection.

Recording will not arm, or Keep take is rejected

Check input selection and sample space. Two bars must fit ten seconds and the remaining frame budget; raising tempo can shorten the take. For the built-in mic, use the local Mac development server with its native helper and microphone permission. A project/pad change after arming can invalidate the destination. Use an offered take/draft download to retain captured data.

An effect or tempo-map edit is rejected

Stop playback before replacing the effect graph or editing the map. Fill Insert 1 before Insert 2. Continuous controls can be automated; changing the graph is a separate edit.

Export fails or no file appears

For a song, create a finite chain with Song end set to Stop. Shorten a render that exceeds its frame/command budget. Check the status message and browser download permissions. MIDI cannot represent every XMP control, and ambiguous same-pitch overlaps can reject.

My project did not restore

Use the same browser, profile and exact local origin. If available, open your portable project copy. Clearing site storage can remove autosaves. Invalid imports do not replace the current valid project. VM storage is separate from Studio’s browser store.

The VM reports project recovery

Use status and recovery-report. A valid previous generation can open read-only; no validated generation means music save/export is refused. recovery-export preserves an archive on the virtual disk. Keep the original disk and files; this workflow does not need an Akai device.
