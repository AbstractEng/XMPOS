# Night Shift

Original XMP house demo: F minor, 124 BPM, six tracks and a complete 36-bar
arrangement ending in Stop. Drums are synthesized by XMP's 909-style kit;
bass, chords, pad and lead use XMP's original subtractive synthesizer presets.
No vendor samples, recordings or firmware are included.

This is the original Night Shift project generated by tools/demo/house-song.mjs,
opened and saved with the current shared song core. Musical content, sounds,
mix, arrangement and project identity are unchanged. The web client pins its
size and SHA-256 in src/demo-night-shift.json and loads it only when no saved
project exists. Browser playback starts only after the user presses Play.

Original XMP code, music and synthesized sounds: Apache-2.0.
